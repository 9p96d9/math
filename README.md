# さわって さんすう図鑑

とく前に、さわって かんかくを つかむ ための 算数教材。
公開URL: https://9p96d9.github.io/math/ （GitHub Pages / master直下）

- `index.html` … 図鑑本体。20モジュール（水そう・通過算・円周率・立体・とけい・角・くらい・わりざん など）
- `drill.html` … 単元別ドリル（小1〜中3、18単元）
- 依存なしの単一HTML。ビルド不要で、そのまま開けば動く

## テスト

```sh
node test/smoke.mjs   # ロジックと 画面の 中身
node test/touch.mjs   # iPadサイズ + 指での操作
```

`smoke.mjs` … 全モジュールを開いて「JSエラー0 / SVGが空でない / 押せないボタンが
残っていない / 横にはみ出さない」を見たあと、円周率のラベル衝突・図形の角のかどの和・
くらいのくり上がりくり下がり・わりざんの商とあまり を検証する。

`touch.mjs` … iPadたて/よこ・iPhoneたての3サイズでレイアウトと44pxのタッチ目標を見て、
CDPで本物の touchStart/touchMove を流し、ドラッグが効くか・その拍子にページが
スクロールしてしまわないかを確かめる。ブラウザは Chromium なので Safari固有の差
（iOSの音声再生ポリシー、SVGのポインタ挙動）までは見られない。そこだけは実機が要る。

Playwright が必要（`npm i -g playwright` でも可。グローバル導入なら自動で探しに行く）。
UIをいじったら、実機で触る前にこれを通しておくと、目視では見のがす種類の不具合を拾える。
